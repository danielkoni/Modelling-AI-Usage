Welcome!

This project aims to explore how AI induced skill decay manifest in a complex social environment. Using the Agent based modelling Mesa Python library we run a model where agents interact and compete on tasks and by doing so change your skill level. There are also given the option to use a performance enhancing option that we call AI skill level.

The final version of the model can be found in the V2_run_batch02.ipynb notebook. Simply download the notebook, install the necessary libraries and run it. Feel free to edit the model as need be.

Furthermore, in V2_run_batch01.ipynb you can find a notebook that produces a comparison between the bottom 20% and top 20% of agents in a nifty linear format. Although the code of the model is up-to-date, some of the descriptions may not be complete.

The V2_ABM_Code.ipynb notebook contains the original code for the second version of the model as well as some graphs and visualisations used to understand the results.

All the other files and notebooks are predecessors to the final version. I kept them in case I would need to bring information or code from there, in those versions AI act as a booster to the current skill of an agent as opposed to a set value to which you jump if you choose to use AI assistance. I kept these files as evidence of my gradual progress as well as a way to quickly access the information if I needed it.
